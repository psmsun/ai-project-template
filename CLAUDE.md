# Project instructions

> **New project?** This is a fresh copy of the ai-project-template. Run the **`init-project`**
> skill once before writing any code — it scaffolds the toolchain, installs the workflow
> skills, and generates this project's `coding-standards` skill. After init, delete this note.

## Coding standards

Once initialized, all coding standards live in the `coding-standards` skill at
`.claude/skills/coding-standards/`.

**Load that skill** before writing code, reviewing changes, or answering questions about
conventions.
